# 发射倒计时协同控制系统（仿真原型）

把推进剂加注、箭体温控、地面设备、人员撤离、天气窗口放进同一条倒计时控制流：
任何环节的提前、暂停、回退都会即时重算后续许可时刻；系统持续判定温差、压力、雷电
风险与设备互锁；错误动作不仅被阻止，还会展示影响传播到了哪些环节；每次处置生成
可回放的时间分支，退出回放即回到真实倒计时阶段。

## 运行

无需安装依赖，直接用浏览器打开：

```bash
open index.html
```

命令行测试：

```bash
npm test
# 或
node tests/engine.test.js
```

## 界面与操作

- **许可时间轴**：六个阶段（撤离 T-40 → 加注 T-25 → 温控 T-15 → 天气 T-10 →
  地面 T-8 → 终端 T-1）各有计划窗口与实时“许可完成时刻”；窗口滑移以秒显示。
- **互锁灯**：撤离、加注量、贮箱压力、温差、雷电、设备互锁、通信共七路
  GO/NO-GO，红/黄/绿实时刷新；T-0 仍有红灯则终端保持 HOLD。
- **多岗位指令台**：可切换指挥员 / 安全岗 / 加注岗 / 地面岗；同一资源 10 秒内
  的低权限指令会被拦截，指挥员可覆盖。
- **故障注入**：泄漏（加注窗口内）、雷暴、通信中断。处置选项弹窗强制在 T-60
  决策点前选择；逾期未决自动中止（scrub）。
- **影响传播**：被阻止的动作弹窗 + 时间轴/互锁灯橙色脉冲，并在日志中给出
  `环节 A → 环节 B` 传播链。
- **时间分支**：每次处置生成独立分支，可单步/自动回放；回放视图只读，
  “返回实时”后真实倒计时阶段保持不变（回放不污染实时状态）。

## 关键规则（引擎实现）

- 冻结：仿真时钟与许可时刻保持不变；冻结期间仅“恢复”指令可执行。
- 加注速率：低/常/高速影响单位时间液位增量，速率调整立即重算许可 T-0；
  压力 > 3.8 bar 时禁止升高速率。
- 备用管路：切换后 45 秒建压暂停；泄漏未处置时禁止带压切换。
- 提前：撤离未完成时提前加注/地面设备被安全互锁拦截；雷电红色禁止提前加注。
- 回退：加注回退使液位回落并作废温控确认（120 秒再确认窗口）；后序已完成时
  拒绝回退撤离。
- 通信：中断期间除冻结外指令排队，恢复后重新校验——仍不满足则拒绝并给出影响链。
- 脱拔：测试全过 + 互锁闭合才可加电，T-30 前禁止执行脱拔。
